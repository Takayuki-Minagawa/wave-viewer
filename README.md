# 📊 Wave Viewer

加速度データの波形分析を行うWebアプリケーションです。

## 🎯 概要

1列の数値データ（加速度データ）を読み込み、時系列波形・フーリエスペクトル・応答スペクトルをリアルタイムで表示・分析するツールです。
**防災科学技術研究所のK-net/KiK-net形式**にも対応しています。

## ✨ 機能

### データ入力
- CSV / TXT / DAT ファイルの読み込み
- **K-net / KiK-net形式の自動検出・読み込み**
- ドラッグ＆ドロップ対応
- サンプリング周波数の設定（K-net形式は自動設定）
- ヘッダー行スキップ機能

### 波形表示
- **加速度波形**（ズーム・パン対応）
- **速度波形**（加速度の積分により自動計算）
- **変位波形**（速度の積分により自動計算）
- X軸: 時間 [sec]
- Y軸: 加速度 [cm/s2, m/s², g] / 速度 [m/s または cm/s] / 変位 [cm]
- ベースライン補正（線形トレンド除去）適用

### フーリエスペクトル解析
- FFT（高速フーリエ変換）による周波数分析
- 振幅スペクトル / パワースペクトル 切替
- 周波数軸の線形 / 対数表示 切替
- 窓関数の選択（Hann / Hamming / Blackman / 矩形）。変更時はFFTのみ再計算
- 窓係数和で振幅を補正し、ゼロパディングによる振幅の縮小を防止
- 「パワー」は片側ピーク振幅の二乗（PSD・RMSパワーではありません）
- Y軸レンジは0.5Hz以上の最大値で自動設定

### 応答スペクトル解析
- **加速度応答スペクトル（Sa）**
- **速度応答スペクトル（Sv）**
- **変位応答スペクトル（Sd）**
- 周期範囲: **0.02s 〜 10.0s**
- 分割: **等比数列で200分割（201点）**
- 減衰定数: **h = 2%, 3%, 5%**

### 統計情報
- データ点数 / 継続時間
- 最大値 / 最小値
- 平均値 / 標準偏差
- RMS（二乗平均平方根）
- ピーク周波数

### データエクスポート
- 加速度データのCSVエクスポート
- 速度データのCSVエクスポート
- 変位データのCSVエクスポート
- 応答スペクトル（Sa/Sv/Sd, h=2/3/5%）のCSVエクスポート
- フーリエスペクトルのCSV（全周波数ビン・振幅・二乗振幅・窓名）
- 全データ（時間・加速度・速度・変位）の一括エクスポート
- 加速度単位が `cm/s2` の場合、速度は `cm/s` で出力
- Excel対応（BOM付きUTF-8）

## 🚀 使い方

### 1. サーバーの起動

```bash
cd wave-viewer
python3 -m http.server 8080
```

### 2. ブラウザでアクセス

```
http://localhost:8080
```

### 3. データの読み込み

#### 1列データの場合
1. **ファイル選択**ボタンをクリック、またはドラッグ＆ドロップ
2. サンプリング周波数を設定（デフォルト: 100Hz）
3. 必要に応じてヘッダー行スキップ数を設定
4. データ単位を選択（cm/s2, m/s², g）して「解析実行」をクリック

解析中は「キャンセル」で停止できます。別ファイルを選択した場合は古い解析を破棄し、最新の選択だけを表示します。新しい解析の開始・失敗・キャンセル時は結果欄を非表示にし、異なる解析の結果が混ざったCSVを出力しません。

#### K-net/KiK-netデータの場合
1. **ファイル選択**ボタンをクリック、またはドラッグ＆ドロップ
2. 自動的にフォーマットが検出され、以下が自動設定されます：
   - サンプリング周波数（例: 100Hz）
   - データ単位（cm/s2）
   - スケールファクター適用
3. そのまま解析が実行されます（設定変更不要）

### 4. 結果の確認

- **上段**: 時系列波形グラフ
- **中段**: フーリエスペクトルグラフ
- **下段**: 応答スペクトル（Sa/Sv/Sd, h=2/3/5%）
- **統計情報**: 各種統計値とピーク周波数
- **エクスポート**: 波形CSV + 応答スペクトルCSV
- **コンソール**: K-netデータの場合、観測点情報などが表示されます

## 📘 簡易マニュアル

1. `ファイル選択` またはドラッグ&ドロップでデータを読み込みます。
2. 読み込み後に自動解析され、加速度・速度・変位・フーリエ・応答スペクトルが表示されます。
3. `cm/s2` データでは速度表示/出力は自動で `cm/s` になります。
4. グラフはホイールでズーム、ドラッグでパン、`リセット` ボタンで初期表示に戻せます。
5. フーリエグラフの `窓関数` を切り替えると、スペクトルとピーク周波数が更新されます。時間波形と応答スペクトルは変わりません。
6. `データエクスポート` の `フーリエスペクトル` は、表示用の間引き前のDC〜Nyquist全ビンをBOM付きCSVで出力します。
7. `応答スペクトル` は `Sa/Sv/Sd`（h=2/3/5%）をCSV出力します。

## 📄 対応データ形式

本ツールは **2種類のデータ形式** に対応しています。フォーマットは自動判定されます。

### 1️⃣ 1列数値データ形式

#### 入力ファイル形式
- CSV（カンマ区切り）
- TXT（タブ区切り、スペース区切り）
- DAT

#### データ例
```
# 1列の数値データ（1行1データ）
0.0000
0.3090
0.5878
0.8090
...
```

#### 対応する数値形式
- 整数: `123`
- 小数: `1.234`
- 科学的表記: `1.23e-4`
- 3桁区切り: `1,234.56`（1列データとして解釈）
- 空行と `#` / `//` で始まるコメント行は無視
- 不正な数値（`1abc`、`NaN`、`Infinity`など）は行・列番号を表示して読み込みを中止
- ヘッダースキップは、空行を含めたファイル先頭からの物理行数

通常の複数列データは先頭列を読みます。ただし `1,234` のように3桁区切り数値として成立する行は1つの数値として扱います。曖昧なデータは1列に整形してください。プログラムからの利用では `delimiter` または `columnIndex` を明示して区別できます。

---

### 2️⃣ K-net / KiK-net形式（防災科学技術研究所）

防災科学技術研究所の強震観測網データに対応しています。

#### 特徴
- **自動検出**: ファイルを読み込むだけで自動的にK-net形式を判定
- **自動設定**: サンプリング周波数、スケールファクター、単位を自動設定
- **メタデータ抽出**: 観測点コード、方向、継続時間などを自動取得

#### データ構造
```
Origin Time       2026/02/05 03:21:00
Lat.              29.1
Long.             130.4
...
Sampling Freq(Hz) 100Hz
Duration Time(s)  60
Dir.              E-W
Scale Factor      7845(gal)/8223790
...
    -734     -591     -441     -309  ...
    -324     -376     -454     -522  ...
```

#### 自動処理される項目
- ✅ サンプリング周波数の自動設定
- ✅ スケールファクターの自動適用
- ✅ データ単位をcm/s2に自動設定（K-net生データの `gal` を換算）
- ✅ ヘッダー17行の自動スキップ
- ✅ 観測点情報の抽出（コンソールに出力）

## ⚙️ 設定パラメータ

| パラメータ | 説明 | デフォルト | K-net形式 |
|-----------|------|-----------|----------|
| サンプリング周波数 | データの取得間隔 | 100 Hz | **自動設定** |
| ヘッダー行スキップ | 先頭からスキップする行数 | 0 行 | **自動処理** |
| データ単位 | 加速度の単位 | **cm/s2** | **cm/s2（自動）** |

> **Note**: K-net/KiK-net形式のファイルでは、設定パラメータは自動的に適用されます。
>
> **Note**: 加速度単位が `cm/s2` のとき、速度は `cm/s` で表示・エクスポートされます（`gal` と同等）。

## 数値の定義と精度

- FFTは対称窓を適用し、元の窓係数の和で正規化した片側ピーク振幅です。DC・Nyquist以外の成分を2倍します。窓補正の根拠は [SciPyのSpectral Analysis](https://docs.scipy.org/doc/scipy/tutorial/signal.html#spectral-analysis) を参照してください。
- 2点以下では窓が退化するため矩形窓として計算します。ビン間の周波数では漏れ・振幅の誤差が残り、ゼロパディング自体で情報分解能は向上しません。
- v2.3.4以前の振幅は窓減衰とゼロパディング分だけ小さくなっていました。今回の補正でスペクトルの振幅値・二乗値が変わります。
- 応答スペクトルは既存のNewmark平均加速度法（β=1/4、γ=1/2）で、記録の時間刻みをそのまま使います。初期相対変位・速度は0、Saは絶対加速度、Sv・Sdは相対応答です。自動細分化はありません。短周期の精度は時間刻みに強く依存するため、短周期側はより細かい刻みとの収束比較が必要です。FFTの窓設定は応答スペクトルには適用しません。
